## Keep practising

Ideas for using the starter app after the workshop:

- Add **editing** for existing expenses.
- Add a **monthly view** that filters expenses by month.
- Add a **search box** for the expense list.
- Export expenses to a **CSV file**.

Try each one with both approaches from the workshop, and compare.
